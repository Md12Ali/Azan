Put your Adhan audio files here (MP3/OGG). File names the app looks for by default:

  fajr_soft.mp3     – calm, soft Adhan used for Fajr
  adhan_full.mp3    – full melodic Adhan for Dhuhr, Asr, Maghrib, Isha
  adhan_short.mp3   – optional short version (first takbir only), selectable in settings

Add more files and they appear automatically in Settings → Adhan sound.
If a file is missing the app falls back to the phone's alarm tone, so alerts never fail.
Use only recordings you have permission to redistribute (many mosques/muezzins share theirs freely –
ask, and credit them in the app's About section).
